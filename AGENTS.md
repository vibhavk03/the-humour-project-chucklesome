# AGENTS.md

## UI conventions
- Use only web-safe fonts in the UI; do not use custom or externally hosted fonts.
- Prefer web-safe sans-serif stacks (e.g., Arial, Helvetica, Verdana, Tahoma, Trebuchet MS, sans-serif).
- Always show motion/animations, regardless of prefers-reduced-motion settings.
- For result tables, show Id (or equivalent) as the left-most column.

## Data conventions
- The database uses cascade deletes; do not manually delete related rows when deleting a record.

## Supabase schema
- The latest database types live in src/types/supabase.ts
- This is generated by running npm run supabase:types
- The user does not want to use a SUPABASE_ROLE_KEY.  All actions should use the logged-in user's JWT key.

## Workflow
- Before finishing work, run `npm run build` to ensure there are no build errors.
